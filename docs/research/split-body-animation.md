# 上下身分层动作样本

用户询问能否制作上下半身分离的动作。本次使用原创疾行小鬼，在现有动作预览中展示“跑步 + 上身挥击”。

[打开分层样本](https://w-sunjun-user.dev.clock-p.com/#/games/test-game?view=animation&asset=moss-runner)。选择“行走”，再点“上身攻击”或“循环上身攻击”。左右实例独立，可以把一侧保留为普通跑步进行对照。

## 制作与规则

- Blender 给小鬼新增 `Spine` 胸腔骨骼，重分配躯干、头、双臂和围巾的归属；骨盆 `Body` 与双腿保留在下身。
- 新增 1 秒 `UpperAttack`，包含蓄力、前挥和收回，只给上身子树打关键帧。既有 Idle、Walk、Death 保留。
- 同一模型仍是一套 12 骨骼的骨架；按轨道划分动作，不拆成两个模型，也不新做一条包含全部组合的“边跑边打”动画。
- 待机/行走分成下身轨道和原上身轨道。攻击只混合 `Spine` 子树：原上身权重为 `1 - w`，攻击权重为 `w`；下身始终保持完整权重。上身自然继承骨盆的移动与起伏。
- 上下身可分别暂停、定位和调速。改变待机/行走不重置正在播放的上身攻击；调整上身动作不重启腿部周期。
- 上身混合权重可调 0～100%，进出攻击各用 0.12 秒过渡。单次攻击结束或主动停止后恢复基础动作的摆臂；死亡和复位立即清除上身层，死亡独占整套骨架。

## 实现范围

源文件仍是 `assets-source/frontier/moss-runner.blend`，GLB 为 `public/assets/frontier/moss-runner.glb`，用 `tools/blender/build_frontier.py -- moss-runner` 重建。预览播放使用 `UpperBodyLayer` 管理这一层，复用同一个 `AnimationMixer`。没有增加通用动画状态机、多层图编辑器或战斗定义字段。

Blender 单独切换到只包含上身关键帧的 Action 时，下身姿态由当前基础动作决定；源文件默认保存在 Idle。生成脚本在单独渲染部分动作前显式恢复未被该动作驱动的骨骼，避免展示图沿用之前的死亡姿态。运行时通过明确的骨骼遮罩排除导出器可能带上的下身静态轨道。

## 验证

`npm run build`、`npm run test:runtime` 通过。`tools/tests/split-body.mjs` 使用实际 GLB，与未经分层的原始 Walk 比较：

- 100 个 1/60 秒步中，骨盆、双腿骨骼的世界变换最大差值为 0；上身攻击明显改变手臂姿态。
- 上身权重 0% 完全恢复原动作；50% 与四元数插值一致；100% 正常覆盖上身。
- 上下身暂停和速度独立；待机/行走切换不重启上身；单次结束及主动停止能恢复摆臂。
- 死亡中断后，完整骨架逐帧与原始 Death 一致；复位、实例隔离和源动画轨道不被修改的检查通过。

逻辑记录：`artifacts/frontier/split-body-checks.json`。浏览器脚本：`tools/browser/split-body-smoke.cjs`；画面、操作与录像记录在 `artifacts/frontier/split-body-browser/`。

浏览器检查已通过，实际查看了并排对照、组合播放、横屏和竖屏画面。覆盖上下身分别暂停、0/50/100% 权重、单次与循环攻击、主动停止、死亡、卸载和重载；页面错误、失败请求均为零。调整权重时立即采样当前姿态，避免暂停状态的控件值先于画面更新。390×844 / 844×390 视口尺寸只用于布局检查，不代表真实手机性能验收。

旧箭塔与 KayKit 骷髅的 `p1-5-6-smoke.cjs` 回归也通过，命令和 Chrome 正常退出；日志为 `artifacts/frontier/split-body-legacy-regression.log`。

当前是原地动画组合样本，未给战斗中的怪物增加攻击能力，也未实现上身自动瞄准、脚部 IK 或根运动匹配。
