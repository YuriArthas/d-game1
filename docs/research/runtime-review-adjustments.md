## 自洽性复核

- **死亡与波次**：死亡立即失去活动资格；完成并不等于暂停，也不等于所有 View 都已经释放。界面明确显示“波次完成 · 死亡表现清理中/已暂停/表现已清理”。完成后的清理可以暂停和恢复。
- **两种时间**：动画使用模拟时间而非未经限制的墙钟增量；后台追赶上限仍是 0.25 秒。出生前的时间不给新单位，死亡前的待展示行走时间不给死亡动作。动作切换的零步姿态同步不推进动画时间。
- **资源归属**：模板拥有共享几何体、材质、贴图和 clip；角色拥有自己的骨骼与 Mixer。按源 Skeleton 的同一引用恢复共享，已证明骨骼及顺序、逆绑定数据原本一致；不凭名字猜测兼容性。
- **计时口径**：CPU 覆盖帧回调、逻辑、表现、提交和探针开销，不含 React/DOM 或浏览器合成。GPU 是异步的另一采样帧，保留帧号；不支持扩展就显示不可用。关闭探针不会关闭渲染。
- **数据规模**：现有 reward、startingGold、baseLives 尚仅校验，不宣称经济已接入。地图占用、目标、冷却、当前血量保留为未来运行时状态，不塞进静态内容。

## 本轮验证结果

`npm run test:runtime` 和 `npm run build` 通过。构建仍有既有的大 chunk 提示，独立游戏入口/拆包属于后续交付步骤。

自动化回归包括：

- 13 个非法内容案例，以及生成、暂停、重开、释放、修改数据生效和固定步一致性。
- 波次完成早于死亡清理、清理期间暂停、完成后波次时间不再增长、重开清除完成状态。
- 当前没有活动敌人但仍有待生成项时不提前完成，后续生成继续。
- 单帧追赶只推进一次动画；同一帧三个不同出生时刻的单位分别得到 0.25/0.15/0.05 秒；帧内死亡不混入之前的行走时间。
- 路线出生和折点方向；常驻摘要不调用单位 inspector。
- 实际 KayKit GLB 的 9 个网格、绑定矩阵和逆绑定信息；Walking_A/Death_A 下累计 29,148 次变形顶点比较与原始 SkeletonUtils 克隆一致；角色间骨骼独立、不同源 skin 不误合并。
- GPU 查询不可用、异步结果、队列上限、失效和释放。

## 后续功能顺序

Draft 已确定网格放置、每塔一格、不堵路，删除升变/放置的重复待确认项；Controller、资源 registry 和策略字段改为随实际功能出现再拆分。

1. **网格放置**：选格、预览、确认/取消、费用、占用、UI 不穿透。桌面和触摸共用规则；非法格、重复占用、金币不足均保持原状态。
2. **单箭塔战斗**：射程内优先剩余路程最短的敌人；逻辑驱动出箭，箭矢追踪原目标、命中一次结算，目标失效不换目标；击杀奖励与漏怪扣命。
3. **关卡与独立交付**：连续波次、奖励、胜负、暂停和重开；单独构建游戏入口。随后再扩展多塔、多敌人、升级与升变。

仍未完成：P1 骷髅正式坐标/重导出复验、P2 真实设备、50 个活动怪物之外叠加死亡实例/塔/箭矢的压力验证、独立游戏构建。当前没有把 P1/P2 标为完成。
