# 蓝银骑兵 Web 动作预览

日期：2026-10-02。用户选定蓝银长枪盾牌重骑兵低多边形三视图，确认骑士和马合计约 2000 三角面、死亡采用马失衡停止与骑手摔落。用户明确该单位是普通骑兵，贴图最高 1024、优先 512 或 256；先制作动作并在 Web 播放，视觉认可后再考虑 Roblox。

## 入口与操作

[打开骑兵动作测试](https://w-sunjun-user.dev.clock-p.com/#/games/cavalry)。这是游戏列表中的独立入口，不接入塔防波次或战斗逻辑。已有网站的登录要求沿用；本轮匿名请求收到飞书认证跳转。构建产物由已有 4173 静态服务提供。

左右实例分别选择待机、奔跑、冲锋和死亡。先选待机/奔跑，再点“上身攻击”或“循环上身攻击”，可观察同一匹马持续移动时骑士用长枪前刺。上下身分别支持速度、暂停和定位，混合权重支持 0～100%。死亡和冲锋切换到全身动作，复位回待机。观察角度包括斜前方、正面、侧面和背面；也可以在画布上横向拖动或触摸滑动，自由旋转两实例而不改变并排位置。

## 资产

- 原创资产：`public/assets/cavalry/cavalry.glb`，354244 字节，**2078 三角面**（骑手、马、长枪、盾牌和马具合计）；长枪从握点到枪尖约 3.0 m。
- 一张 **256×256 调色板贴图**、一个材质、27 根骨骼、一套 skin（原始 2078 面回退资产）。
- 当前页面默认加载 `public/assets/cavalry/cavalry-tripo.glb`：直接以原始蓝银低多边形三视图重新运行 RAB 同款 Tripo `multiview_to_model`，face limit 5000，原始输出 4881 面；再由同一 mesh task 运行 Tripo `texture_model`，删除持剑侧重复盾牌、加入颈甲桥并绑定，变体为 **4766 三角面**，一张 **512×512 Tripo 烘焙 PNG**、一个材质、27 根骨骼和一套 skin；原 2078 面 GLB 保留为回退基线。
- Tripo 变体忠实保留原始四视图中的短剑；回退 `cavalry.glb` 才是旧长枪版本。当前 Tripo Attack 仍沿水平前向执行“后收—穿刺—回撤”，若要 Tripo 本体使用长枪，应先换成长枪四视图再重跑 mesh task。
- 可编辑源：`assets-source/cavalry/cavalry.blend`；生成脚本：`tools/blender/build_cavalry.py`。
- 五个动作：Idle 2.2s、Run 0.9s、Attack 1.0s、Charge 0.7s、Dead 1.8s。
- 单一骨架中从 `RiderSpine` 分层；基础层保留马、骑手骨盆和腿。Attack 仅驱动骑手上身；Charge/Dead 独占全身。
- 奔跑和冲锋采用不同步幅与相位的四拍马步：支撑段较长，摆动段抬腿并在落地前减速；马腿接地由离线 IK 烘焙。长枪攻击保持枪杆水平，沿马的前进轴完成后收、穿刺和收回三个阶段。死亡独立求解马与摔落骑手的接地，再烘焙到同一骨架。运行时不修补穿地、不执行布娃娃。
- 根节点不移动，当前只做原地动作。完整动作范围写入资产 extras，供取景使用。

## 验证

Blender 导出后重新导入，确认单一骨架、完整动作和贴图保留。`npm run build`、`npm run test:runtime` 通过。实际 GLB 检查见 `tools/tests/cavalry.mjs` / `artifacts/cavalry/checks.json`：

- 上身攻击与未分层的原始 Run 比较，全部马骨骼、骨盆、骑手双腿的世界变换最大误差 **0**。
- 上身明显改变右臂和长枪姿态；0/50/100% 权重、独立时钟、单次结束恢复、冲锋/死亡清层、实例隔离通过。
- 实际变形顶点以 60Hz 抽样检查有限数值与地面接触；Idle 最大约 0.007m 呼吸下沉，Run/Charge/Dead 最大约 0.002m 插值误差，无大幅穿地。循环首尾与死亡最后 0.15s 的定格通过。
- 图片尺寸直接从实际内嵌 PNG 读取，为 256×256。CPU 动作检查仅使用图片尺寸代理，不声称完成纹理解码/渲染；真实 PNG 解码、UV 和 WebGL 显示由浏览器检查覆盖。
- 原有塔防、箭塔、原创模型和小鬼分层回归通过。

`tools/browser/cavalry-smoke.cjs` 已在已有 4173 静态服务上通过：独立入口、实际纹理 GLB、拖拽旋转、四个观察角度、五个动作、独立上下身暂停、0/50/100 权重、冲锋/死亡打断、实例重建、三次资源卸载/重载、844×390 和 390×844 布局、小鬼分层回归。页面错误和失败请求均为零。已实际查看奔跑叠加长枪穿刺、冲锋、坠马死亡和横/竖屏截图。记录与录像在 `artifacts/cavalry/browser/`。

已有静态服务读回的 GLB 与源文件 SHA-256 一致；公网匿名请求受现有登录限制，因此没有把匿名公网页面当成通过证据。

## 验收边界

T3 的 preview_status 和 preview_open 均返回环境未连接协作浏览器，因此本轮使用 Chromium + SwiftShader 的 headless 检查。Web 验证和截图检查不等于真实手机 GPU 性能，也不等于用户的美术/动作认可。Roblox 导入、动画绑定、网络同步和性能均未开展，等待用户先检查这版 Web 预览。
